# APLICAȚIE PENTRU GESTIONAREA DOCUMENTELOR CONTABILE
Aplicație web dezvoltată pentru lucrarea de licență, destinată gestionării documentelor și firmelor.

## Descriere

Aplicația permite utilizatorilor să gestioneze firme, documente și notificări într-o interfață web.

## Funcționalități

- autentificare și înregistrare utilizatori
- gestionarea firmelor
- adăugarea și gestionarea documentelor
- gestionarea utilizatorilor
- sistem de notificări
- profil de utilizator
- roluri și acces pentru administratori

## Tehnologii

- Laravel
- PHP
- MySQL
- Blade
- Tailwind CSS
- JavaScript
- Vite

## Instalare
composer install
npm install

Configurează fișierul .env și apoi rulează:

php artisan migrate
npm run build
php artisan serve
